# Текущее состояние и план

Версия плагина — **0.1.6**. База — стабильный **Minishop 3.8.1** из
[dev/minishop.json](../dev/minishop.json). Поведение определено в
[требованиях](specification.md), проверки — в [матрице приёмки](acceptance.md).

## Поставка

Сборка подписанного ZIP, индекс для установки по URL репозитория и публикация
в основной ветке реализованы и проверены локально. Штатный импортёр Minishop
принимает сгенерированный индекс; проверки охватывают подпись, неизменность
опубликованной версии, повторную публикацию и устаревший исходный commit.
Настройка GitHub описана в [инструкции сборки](ci-packaging.md).

Разработка использует отдельный checkout Minishop и не требует других плагинов.
Локальный набор включает типы, линтеры, unit/DOM, PostgreSQL, браузер и полный цикл
установки/обновления пакета. Подробности — в [матрице проверок](acceptance.md).

## Ограничения и оставшиеся задачи

- Действующие или будущие `FlexibleTrafficLimit` не поддерживаются; см.
  [совместимость](minishop-compatibility.md).
- Локальные интеграционные тесты используют HTTP-двойники панели и Telegram.
  Конкретная рабочая панель, провайдеры входа/оплаты и Telegram-клиенты требуют
  проверки на выделенных аккаунтах перед рабочим запуском.
- Настройка GitHub Secret и первый удалённый запуск сборки не подтверждены локальными
  проверками. Публикация репозитория и установка на рабочий бот остаются отдельными действиями.
