# Текущее состояние и план

Версия плагина — **0.1.9**. База — стабильный **Minishop 3.8.1** из
[dev/minishop.json](../dev/minishop.json). Поведение определено в
[требованиях](specification.md), проверки — в [матрице приёмки](acceptance.md).

Проверка Minishop **3.8.2** от 14 октября 2026 года выявила два препятствия для
принятия новой базы: неучтённые автоплатежи CisPay/Cryptomus и расходование
отложенного приветственного бонуса при корпоративном выходе. Рабочий код
не исправлялся; результаты и регрессии — в [отчёте](minishop-3.8.2-assessment.md).

## Реализовано

| Область | Состояние |
| --- | --- |
| Пакет и интеграция | Plugin API/host API 1, совместимость по возможностям ядра, адаптер Minishop, десять миграций |
| Контракты | Тариф, абсолютный срок, необязательные сквад и управляющий, удаление пустой подписки |
| Приглашения | Одноразовые и несколько постоянных кодов, изменение лимита, резервы, повторный показ, отзыв, замена и удаление; создание и правка доступны управляющему |
| Членство | Предпросмотр, подтверждение, ручное добавление из админки, выход, исключение и устойчивые повторы |
| Доступ | Применение условий через Minishop, новый триал или отключение при выходе |
| Фоновые операции | Очередь и общий шестичасовой обход нынешних участников; применение условий только при отклонениях |
| Управление | Админка, кабинет управляющего, назначение и отзыв роли из участников, профили, трафик, устройства и диагностика |
| Пользовательский UI | Вход из настроек, код/ссылка, членство и выход, RU/EN |
| Удаление аккаунта | Закрытие членства и отмена заданий средствами БД, в том числе без worker |
| Локальная проверка | PostgreSQL, сервисы Minishop, DOM/Chromium, установка и обновление подписанного пакета |
| Документация | Установка по URL репозитория, требования, руководства и галерея интерфейсов в [README](../README.md#скриншоты) |

Сверка сравнивает условия в Minishop и свежем снимке панели: срок, тариф, состояние
доступа, лимиты, тег и сквады с учётом правил ядра для ручных исключений и бонусов.
При совпадении отмечается успешная проверка без записи профиля, подписки и сквадов
и без изменяющих запросов в панель. Недоступная панель оставляет операцию на повтор.
Регрессионные проверки контролируют отсутствие записей и HTTP-изменений, исправление
отклонений с каждой стороны и повторную сверку после восстановления.

## Поставка

Версия 0.1.9 добавляет ручное подключение существующих аккаунтов из списка участников,
отзыв роли управляющего отдельной кнопкой, создание обоих типов кодов и изменение
лимитов управляющим. Миграция 0010 разрешает несколько постоянных кодов, сохраняя
старые коды и счётчики. Индекс и ZIP выпуска публикуются штатным заданием Actions.

Исправлен ложный конфликт при выходе и исключении: изменение поколения членства
сохраняется до повторного чтения в штатной сессии Minishop с `autoflush=False`.
Регрессия воспроизведена до исправления в трёх API-сценариях. Управляющий может
выйти или быть исключён, сохранив роль; отзыв роли сохраняет членство.

Сборка подписанного ZIP, индекс для установки по URL репозитория и публикация
в основной ветке реализованы и проверены локально. Штатный импортёр Minishop
принимает сгенерированный индекс; проверки охватывают подпись, неизменность
опубликованной версии, повторную публикацию и устаревший исходный commit.
Манифест содержит название и описание плагина, локализуемые заголовки админки
и требования `user_ui: 1`, `ui_composition: 1`. Проверенная ревизия записана
справочно; установка не требует совпадения commit ядра.
Настройка GitHub описана в [инструкции сборки](ci-packaging.md).

Разработка использует отдельный checkout Minishop и не требует других плагинов.
Локальный набор включает типы, линтеры, unit/DOM, PostgreSQL, браузер и полный цикл
установки/обновления пакета. Подробности — в [матрице проверок](acceptance.md).

Для 0.1.9 прошли Ruff, строгий mypy, TypeScript, сборка, 38 unit-тестов,
54 DOM-теста, полный прогон 324 PostgreSQL-тестов и 22 целевые проверки приглашений
после уточнения повтора создания при изменённом лимите. Chromium прошёл 43 сценария
в preview и 8 в настоящей оболочке Minishop, в RU/EN на мобильном и настольном экранах.
Подписанный пакет прошёл установку, обновление, повторную установку, выключение/
включение и сохранение данных с десятью миграциями. Рабочая панель не использовалась.

## Ограничения и оставшиеся задачи

- До принятия Minishop 3.8.2 исправить обе ошибки из
  [проверки совместимости](minishop-3.8.2-assessment.md) и повторить приёмку.
- Действующие или будущие `FlexibleTrafficLimit` не поддерживаются; см.
  [совместимость](minishop-compatibility.md).
- Локальные интеграционные тесты используют HTTP-двойники панели и Telegram.
  Конкретная рабочая панель, провайдеры входа/оплаты и Telegram-клиенты требуют
  проверки на выделенных аккаунтах перед рабочим запуском.
- Ранее отмеченная нестабильность фоновых тестов при скачках системного времени
  в текущем полном прогоне не воспроизвелась: 324 PostgreSQL-теста прошли.
- Успешная сборка и публикация версии 0.1.9 в GitHub Actions ещё не подтверждены.
  Push и установка на рабочий бот остаются отдельными действиями.
