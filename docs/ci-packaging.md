# Сборка установочного пакета в GitHub Actions

Статус: в работе. Ветка: `vibe/signed-artifact-ci`.

## Решение владельца от 9 октября 2026 года

GitHub Actions после push в любую ветку должен собирать подписанный плагин,
который можно скачать и загрузить в работающий Minishop. Проверки продукта
выполняются локально во время разработки. Actions не скачивает Minishop и
kiro-wheel, не устанавливает их зависимости и не запускает стенды или тесты.

Это изменение процесса S01/S10: прежний workflow воспроизводил локальную
приёмку и подписывал тестовый пакет временным ключом. Новая сборка использует
постоянный ключ издателя из GitHub Secret и сохраняет готовый результат как
артефакт запуска. Публикация в Git-ветку, Release и установка на бот в эту
задачу не входят. Бизнес-правила, миграции и заявленная совместимость неизменны.

Формат определяется [документацией пакетов Minishop](https://minishop.minidoc.cc/development/plugins/):
ZIP с `plugin.json`, SHA-256 payload-файлов, открытым ключом издателя и
Ed25519-подписью канонического manifest в `signatures/ed25519.sig`.
Генератор уже реализует этот формат; зависимость от валидатора ядра переносится
в явно включаемую локальную проверку. В Actions достаточно исходников плагина,
зависимостей сборки frontend и библиотеки подписи.

## Критерии приёмки

- Workflow запускается после push в любую ветку; сборка не требует checkout
  соседних проектов, Docker, PostgreSQL или зависимостей Minishop.
- Выполняются сборка frontend, упаковка, подпись и сохранение артефакта.
  Тесты, линтеры, проверки типов и интеграционные прогоны остаются локальными.
- Постоянный Ed25519-ключ поступает только в шаг подписи через Secret
  `MINISHOP_CORP_SIGNING_KEY` (base64 от 32 приватных байт). При отсутствующем
  или некорректном секрете сборка завершается понятной ошибкой; новый ключ
  автоматически не создаётся, секрет не выводится и не входит в пакет.
- Артефакт содержит установочный ZIP, `minishop-plugin.json`, открытый ключ
  и `SHA256SUMS`. В документации объяснено, какой ZIP загружать в Minishop,
  поскольку скачанный Actions artifact сам является внешним ZIP-контейнером.
- Автономная сборка локально воспроизводится без доступа к Minishop и
  kiro-wheel. Её результат принимается штатным локальным установщиком Minishop;
  постоянство ключа и воспроизводимость пакета сохраняются.
- README, правила разработки и инструкция установки соответствуют новому
  процессу. Все обязательные проверки перед коммитом выполняются локально.

## Результат

Реализация и локальная проверка ещё не завершены. Настройка секрета в GitHub
и удалённый запуск не считаются выполненными по наличию workflow в репозитории.
