# minishop-corp 1.1.2

- При добавлении участника и назначении управляющего можно искать по имени и
  фамилии. При нескольких совпадениях администратор выбирает нужный аккаунт по ID.
- Статусы ожидания, выхода и ошибок показываются рядом с профилем участника.
  В колонке действий остаются кнопки.
- Фоновые обновления сохраняют ввод, фокус и прокрутку. Если оболочка Minishop
  пересоздаёт раздел, текст поиска участника восстанавливается в той же странице
  для прежнего администратора и контракта.

Исправления проверены на Minishop 3.8.3 и 3.8.5. На 3.8.5 прошли 62 unit-теста,
63 DOM-теста, 419 интеграционных тестов PostgreSQL и 55 сценариев Chromium.
В штатной админке отдельно проверены добавление по имени и восстановление поиска
при возврате фокуса. [Текущее состояние](../implementation-plan.md).
