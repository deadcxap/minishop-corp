# minishop-corp 1.1.1

Исправлена интеграция с новыми настройками рассылок Minishop 3.8.5:

- Список групп пользователя открывается без HTTP 500, включая корпоративные
  подписки, сохранённые наборы, аудитории других плагинов и обязательного канала.
  Корпоративные группы определяются по БД даже после перезапуска; удалённые
  контракты и бывшие участники не возвращаются из устаревшего каталога.
- Штатные исключения применяются к получателям и счётчикам конкретной корпоративной
  аудитории. Пользователь остаётся виден в своих группах для обратного включения.
  Исключение из всех нынешних групп, включение и сброс используют API Minishop.
  Отложенная рассылка повторно учитывает исключения при начале доставки.
- Заголовок корпоративной плитки использует типографику установленного Minishop:
  12 px на 3.8.3/3.8.4 и 14 px на 3.8.5. Штатные классы применены только к DOM плагина.

Поддержка Minishop 3.8.3 и 3.8.4 сохранена: отсутствующий DAL исключений не импортируется,
нативные аудитории и провайдеры остаются в исходном сервисе Minishop. База сборки — 3.8.3.
Схема, миграции, капча корпоративного триала и правила подписок не менялись.

Локальная приёмка: 378/392/417 интеграционных тестов на 3.8.3/3.8.4/3.8.5
соответственно, по 62 unit, 59 DOM и 55 браузерных сценариев на каждом ядре.
Ожидаемых падений нет; на старых ядрах пропущены только отсутствующие возможности.
Проверен HTTP-переход с опубликованной 1.1.0 на 1.1.1 с сохранением данных.
[Полные результаты и границы проверки](../minishop-compatibility.md#исправления-в-111).
