# minishop-corp 1.1.3

- Корпоративный доступ и стандартный триал после выхода или исключения сохраняют
  отключённое автопродление с личного баланса в Minishop 3.8.6. Миграция защищает
  ранее выданные корпоративные периоды и действующие триалы этих операций.
- Штатный редактор снова загружает корпоративные аудитории и группы по платформам
  устройств. Подготовленная корпоративная аудитория доступна при первом открытии.
- В общем списке пользователей Minishop 3.8.6 доступны столбцы «В корпконтракте»
  и «Корпоративная подписка» и фильтр по наличию членства. Истёкшая подписка
  сохраняет участников в списке.

На ядрах без расширения `admin_users_table` доступен штатный список пользователей.
Для установки используются прежние требования к Plugin API и frontend host API.
[Совместимость и результаты проверки](https://github.com/deadcxap/minishop-corp/blob/v1.1.3/docs/minishop-compatibility.md#исправления-в-113).
