# minishop-corp 1.0.0

Первый стабильный выпуск корпоративных подписок для **Minishop 3.8.1**.

## Возможности

- Корпоративные контракты с общим тарифом, сроком и управляющим.
- Вступление по одноразовому или постоянному приглашению с лимитом использований,
  ручное добавление, выход и исключение с переходом на стандартный триал по настройкам магазина.
- Рассылки участникам одной или нескольких корпоративных подписок через штатный
  редактор Minishop. Доступ к рассылкам есть только у администратора магазина.
- Обновлённые админка и Mini App: компактные таблицы участников и приглашений,
  действия с иконками и подсказками, поддержка RU/EN, светлой и тёмной темы.
- Фоновая сверка условий, защита повторных и одновременных операций,
  сохранение данных при обновлении и переустановке плагина.

## Установка и обновление

В Minishop → Плагины → Установить из GitHub укажите
`https://github.com/deadcxap/minishop-corp`, подтвердите издателя и включите плагин.
Для ручной установки используйте вложенный **minishop-corp-1.0.0.zip**.
Архивы исходников GitHub (`Source code`) не являются установочным пакетом.

При обновлении существующие контракты, приглашения и участники сохраняются.
Как и перед любым обновлением, сделайте резервную копию базы и хранилища плагинов.
Состав поставки: подписанный ZIP, `minishop-plugin.json`, `publisher.pub` и `SHA256SUMS`.
В индексе и списке хешей путь ZIP указан относительно корня репозитория (`packages/`).

## Совместимость

Проверенная база — **Minishop 3.8.1**, Linux x86_64, Python 3.12,
Plugin API 1 и frontend host API 1. Версию Remnawave определяет сам Minishop.

**Minishop 3.8.2 пока не поддерживается:** обнаружены несовместимости с новыми
автоплатежами и отложенным приветственным бонусом. Аккаунты с действующими или
будущими гибкими квотами `FlexibleTrafficLimit` также не поддерживаются.
Подробности — в документации совместимости репозитория.
