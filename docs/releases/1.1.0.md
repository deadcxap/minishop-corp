# minishop-corp 1.1.0

Выход и исключение из корпоративной подписки работают при включённой капче
Minishop 3.8.3. Пользователь автоматически получает один новый стандартный триал
на операцию, в том числе при фоновом исключении без его участия.
Обычная выдача триала Minishop сохраняет капчу.

Исключение действует только в серверном адаптере корпоративной выдачи: настройки
магазина и подтверждение капчи аккаунта не меняются, фиктивный платёж не создаётся.
Используется параметр штатного сервиса `captcha_verified_payment`, пропускающий
проверку для одного вызова. В ядре он предназначен для оплаченного триала;
корпоративное применение — принятое решение, требующее проверки при обновлениях.

Повтор после сбоя сохраняет исходные даты и не выдаёт дополнительный триал.
При отключённом триале или неположительном сроке корпоративный доступ снимается
без триала. Собственная схема, миграции и интерфейсы плагина не менялись.
Основная база приёмки обновлена до Minishop 3.8.3. На 3.8.2 новый параметр
не передаётся: прежний сценарий сохраняется и проверен регрессией.
