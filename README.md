# minishop-corp

Плагин Remnawave Minishop для корпоративных клиентов: общие сроки контрактов,
вступление по приглашению и управление участниками со стороны организации.
Корпоративная оплата происходит вне бота.

Реализованы каркас и стенд S01, адаптер доступа S02, хранилище и API контрактов S03.
В S04 добавлены выпуск, отзыв и замена приглашений, резервы активаций и API
предпросмотра с защитой через Minishop. Q-01 согласован: 1 попытка/мин,
после 5 ошибок — 1/15 мин, после ещё 4 — 1/час; сброс через 3 часа без ошибок.
S05 добавляет API вступления, выхода и исключения, очередь операций и безопасные
повторы через Minishop. Без доступного триала выход отключает доступ; автопродление
и незавершённые платежи блокируют вступление. S06 добавляет немедленное распространение
версий, одну общую сверку всех контрактов раз в 6 часов и API состояния синхронизации.
Следующий этап — S07: профили и статистика участников через Minishop. UI пока остаётся
каркасом.
