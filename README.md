# minishop-corp

Плагин Remnawave Minishop для корпоративных клиентов: общие сроки контрактов,
вступление по приглашению и управление участниками со стороны организации.
Корпоративная оплата происходит вне бота.

Реализованы каркас и стенд S01, адаптер доступа S02, хранилище и API контрактов S03.
В S04 добавлены выпуск, отзыв и замена приглашений, резервы активаций и механизм
защиты от подбора через Minishop. Подключение пользовательской проверки кодов
ожидает выбора численных параметров Q-01. UI остаётся каркасом; вступление и выход
будут подключены в S05, этап S04 пока не завершён.
