# minishop-corp

Плагин Remnawave Minishop для корпоративных клиентов: общие сроки контрактов,
вступление по приглашению и управление участниками со стороны организации.
Корпоративная оплата происходит вне бота.

Завершён S01: Python-плагин, защищённые тестовые маршруты, отдельные ESM-модули
кабинета и админки, RU/EN, изолированный стенд Minishop и проверки.
Корпоративные операции пока не реализованы. Следующий этап — S02, адаптер доступа.
