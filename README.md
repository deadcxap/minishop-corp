# minishop-corp

Плагин Remnawave Minishop для корпоративных клиентов: общие сроки контрактов,
вступление по приглашению и управление участниками со стороны организации.
Корпоративная оплата происходит вне бота.

Сейчас зафиксированы требования; реализация плагина ещё не начата.

## Документация

- [Техническое задание](docs/specification.md) — согласованное поведение, границы
  первой версии, критерии приёмки и параметры, которые ещё нужно определить.

Все изменения выполняются в этом репозитории. `remnawave-minishop` и `kiro-wheel`
служат источниками для чтения и не изменяются.
