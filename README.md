# minishop-corp

Плагин Remnawave Minishop для корпоративных клиентов: общие сроки контрактов,
вступление по приглашению и управление участниками со стороны организации.
Корпоративная оплата происходит вне бота.

Администратор создаёт контракт с тарифом, внешним сквадом, точным сроком и управляющим.
Пользователи вступают по одноразовому или постоянному коду с лимитом использований.
В кабинете видны группа, срок и выход; управляющий видит участников, профили, трафик
и устройства, может исключать пользователей и менять постоянный код.

Подписками управляют сервисы Minishop. Изменение условий применяется ко всей группе;
одна общая сверка раз в 6 часов возвращает срок к договорному. Выход/исключение выдаёт
новый стандартный триал, а при недоступном триале отключает корпоративный доступ.
Предусмотрены очередь операций, безопасные повторы, защита от подбора и RU/EN.

Текущий кандидат — **0.1.2** для стабильного Minishop **3.8.1**
(`bc3379812b370ed4420b97338fc24fce5c87f1a6`), Linux x86_64, Python 3.12.
Подготовлены генератор подписанного ZIP и локальная приёмка S10. Публичного выпуска
пока нет; до рабочего запуска остаётся проверка реального окружения.
Ограничение гибких квот (C-01) сохраняется. Штатное удаление участника или управляющего
не требует предварительного выхода и работает при выключенном плагине; история
сохраняется. Поведение C-02 пересмотрено и описано в инструкции эксплуатации.

Начните с [установки и эксплуатации](docs/installation.md),
[результатов приёмки](docs/acceptance.md) и [CHANGELOG](CHANGELOG.md).

После push в любую ветку GitHub Actions собирает **подписанный установочный ZIP**
и сохраняет его в **Artifacts** запуска. Один раз настройте постоянный ключ издателя
в Secret `MINISHOP_CORP_SIGNING_KEY`; порядок описан в инструкции установки.
Minishop/kiro-wheel в Actions не скачиваются, проверки выполняются локально при разработке.
